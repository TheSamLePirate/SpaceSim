Some times you may need to compile your own executables. This article should help you do that. Before you can compile anything you will need the engine source code. You can find instructions on how to do that on your platform in [this article](http://www.hard-light.net/wiki/index.php/Getting_the_FreeSpace2:_SCP_Source_Code).

After getting the code, you need to run this git command:

```git submodule update --init --recursive```

Or you need to clone the repository with the ```recursive``` option.
